# 园规通 — 风景园林设计规范智能助手

自然语言查询，精确条款引用。覆盖 **11 本**风景园林核心国标/行标，**1562 条**条款。

---

## 功能特性

- **自然语言检索**：输入问题即可检索相关规范条款，支持数值查询、事实查询、设计应用、跨规范对比、概念查询
- **精确引用**：LLM 生成回答时自动附上规范名称 + 条款号 + 原文摘录
- **强制规范优先**：系统提示引导 LLM 在园林/消防/无障碍三个领域内优先引用全文强制规范 GB55014/GB55037/GB55019
- **表格数据清洗**：PDF 文本层提取时自动分离粘连的表格数值，确保 LLM 可读
- **废止标记**：187 条旧强制条文标记"强条已废止"，引用时给出新规范替代方案
- **邀请码系统**：每人每天 20 次提问，支持赞踩反馈收集
- **对话日志**：SQLite 持久化所有问答记录，按邀请码统计使用情况

---

## 技术架构

```
用户提问 → Streamlit 界面
              ↓
       混合检索（向量 50% + jieba 关键词 50% + 强制规范 12% boost）
              ↑
       ChromaDB 向量库（1562 条，bge-small-zh-v1.5 / 512d）
              ↑
       条款切分（正则匹配 + 全角/半角句点统一 + 噪声过滤）
              ↑
       PDF 解析（PyMuPDF 文本层 + 表格数字粘连自动分离）
              ↓
       DeepSeek-chat → 精确引用回答（领域约束 prompt）
```

| 前端 | Streamlit | 单文件 app.py |
